# 抽象关系：of、for、with、without、about、like、except

**这一组今天表示抽象的关系：属于谁、给谁或为了什么、和什么在一起、有没有、关于什么、像什么、除去什么。** 这些介词不配图，但它们本来也都是空间或形状上的词，下表“本义”一列写的就是这个。

| 介词 | 本义 | 从本义怎么推出来 | 例句 |
| --- | --- | --- | --- |
| **of** | 离开、从……出来。of 和 off 本来是同一个词，of 是不重读的读法；到中古英语时期，of 被用来翻译法语里表示“……的”的那个词，于是有了“……的”这层意思 | 翻译带来的“……的” | What's the colour **of** the apple? 这个苹果是什么颜色的？ |
| | | 从苹果里称出两公斤 | I bought two kilos **of** apples. 我买了两公斤苹果。 |
| | | 从这一堆里取出一部分，表示属于一群，常用在 some 后面 | Some **of** the apples are bad. 这些苹果里有一些坏了。 |
| | | of 用在某些形容词后面，引出这种感情所关联的人或物。骄傲从哪里来，of 后面就是什么 | We are proud **of** our apples. 我们为自己种的苹果感到骄傲。 |
| | | of 可以用来评价某人的行为：这份好意出自你 | It's kind **of** you to give me an apple. 你给我一个苹果，真是太好了。 |
| **for** | 在……前面、当着……的面。for 很早就还有“为了……的缘故”“代替”“因为”等意思 | 为了某人 → 东西是给他的 | This apple is **for** you. 这个苹果是给你的。 |
| | | 站在某人的位置上 → 替他做。for 早期就有“代替”的意思 | Can you wash the apples **for** me? 你能帮我洗洗苹果吗？ |
| | | for 早期就有“为了……的缘故”的意思：为了苹果去市场，就是去买苹果，也就是“为了得到” | I went to the market **for** some apples. 我去市场买点苹果。 |
| | | for 早期就有“因为”的意思，表示理由或原因，比如 The town is famous for its church.（这个镇以它的教堂闻名） | This farm is famous **for** its apples. 这个农场以苹果出名。 |
| | | 代替 → 拿一样东西顶替另一样 → 交换 | I bought three apples **for** ten yuan. 我花十元买了三个苹果。 |
| | | for 可以说某件事对某人来说有多难、多必要（It's useless for us to continue. 我们再做下去也没用）。for 后面是“对谁而言” | It's important **for** us to eat fruit every day. 每天吃水果对我们很重要。 |
| **with** | 对着、对抗。with 最早表示“对抗、相对”，到中古英语时期才转为“和……在一起”；withdraw（撤回）这类词里还留着“对着”的意思 | 本义还在：和某人对着干，比如 to fight with somebody（和某人打架） | The boys fought **with** each other over the last apple. 男孩们为了最后一个苹果打了起来。 |
| | | 后来的意思：在一起 | I ate apples **with** my friends. 我和朋友们一起吃苹果。 |
| | | 在一起 → 身上带着 | Look at that tree **with** lots of red apples! 看那棵结满红苹果的树！ |
| | | 手里带着 → 用它来做 | Cut the apple **with** a knife. 用刀切苹果。 |
| | | with 能说明用什么装满、盖住某物：篮子和苹果在一起，被苹果填满 | The basket was filled **with** apples. 篮子里装满了苹果。 |
| | | 这里的 with 表示“涉及、对于”。with 早期也有“朝着、对着”的意思，生气这件事是对着她的 | Don't be angry **with** her. 别生她的气。 |
| **without** | 在外面。with 加 out，最早意思是“在……外面”，和 within（在里面）相对；约 1200 年起有“缺少”的意思，和 with 相对 | 不和这样东西在一起 → 没有 | He went to school **without** breakfast. 他没吃早饭就去上学了。 |
| | | 没带在身上 | Don't go out **without** your coat. 别不穿外套就出门。 |
| | | 没有这个动作 | He took my apple **without** saying anything. 他一声不吭就拿走了我的苹果。 |
| **about** | 在外面一圈。由 on、by、out 三部分合成，最早是“在……外围、绕一圈、在附近”，13 世纪中期起有“关于”的意思 | 围着一个东西转 → 话题围着它转 | This is a book **about** apples. 这是一本关于苹果的书。 |
| | | How about ...? 用来提建议。字面是“围绕去摘苹果这件事，（你觉得）怎么样？” | How **about** going to pick apples? 去摘苹果怎么样？ |
| **like** | 形状相同。like 本义“有同样的特征”，字面是“有着相应的身体、形状” | 本义直接用：相似 | This tomato looks **like** an apple. 这个西红柿看起来像个苹果。 |
| | | 问它像什么 → 问它是什么样子，也就是问对某人某物的看法 | What's the new apple **like**? It's very sweet. 这种新苹果怎么样？很甜。 |
| | | 和苹果、梨同一个样子的 → 举例子 | I like fruits **like** apples and pears. 我喜欢苹果和梨这样的水果。 |
| **except** | 拿出去。ex- 是“出去”，cept 是“拿”，合起来是“拿出去” | 把这一个拿出去，不算在里面 → 除了。except 用在唯一不符合前面说法的那个人或物前面 | I ate all the apples **except** the green one. 除了那个青的，其余苹果我都吃了。 |

上面最后一个 like 例句里，第一个 like 是动词“喜欢”，第二个 like 是介词“像”。

**中考易错点：**
- except 和 besides 从本义就分得开：except 是“拿出去”，不算在内；besides 是“在旁边”，在肯定句和疑问句里表示旁边还有，算在内。例如：I like all sports except football.（除了足球，别的运动我都喜欢）What other sports do you like besides football?（除了足球，你还喜欢什么运动？）
- 介词后面接名词。要在介词后面放一个动作，英语用动词的 -ing 形式，让它像名词一样用：How about going ...、without saying ...。
- What's it like? 问的是“它怎么样”（性格、感受、特点），What does it look like? 问的是“它长什么样”。like 是“像”，What's it like 是“它像什么”，问整体给人的感觉；加上 look 就只问“看起来像什么”。
