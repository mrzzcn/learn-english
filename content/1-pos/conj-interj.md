# 连词与感叹词

## 连词

**连词就是“把东西连在一起的词”。** 它的英文名 conjunction 拆开看：con- 是“一起”，中间的 junct 是“连、套在一起”，-ion 把动作变成名词。合起来是“连在一起”，所以它的工作就是把词、短语或句子连起来。

连起来的两部分，地位可能相同，也可能一主一从。按这一点，连词分成两类：并列连词连接“同一种语法类型”的两部分；从属连词把后面的句子变成从句，而从句“需要一个主句才能成为完整的句子”。

| 类别 | 连起来的两部分 | 常见连词 | 例句 |
| --- | --- | --- | --- |
| 并列连词 | 地位相同：词和词、短语和短语、句子和句子，各自站得住 | and、but、or、so<br/>成对的：both … and、either … or、neither … nor | I picked the apples **and** Tom washed them. 我摘苹果，汤姆洗苹果。 |
| 从属连词 | 一主一从：连词带着的那半句是从句，单独说不完整，要挂在主句上 | that、if、whether、when、while、before、after、until、since、as soon as、because、so that、although、than 等 | I think **that** the apple is sweet. 我觉得这个苹果是甜的。 |

怎么分辨：把连词和它带的那半句单独拿出来念。“and Tom washed them”去掉 and 就是完整的一句 Tom washed them；“that the apple is sweet”单独说出来，听的人会问“然后呢？谁觉得？”——它在等主句。

本义依据：[etymonline: conjunction](https://www.etymonline.com/word/conjunction)。用法依据：[剑桥语法：Conjunctions](https://dictionary.cambridge.org/zhs/%E8%AF%AD%E6%B3%95/%E8%8B%B1%E5%BC%8F%E8%AF%AD%E6%B3%95/conjunctions)。

### 并列连词：and、but、or、so

**并列连词两边的地位相同，谁也不依附谁。** 这四个词的用法看起来很多，其实每个都从一个很朴素的本义长出来。下表“怎么推出来”一列写从本义到用法的那一步。

| 连词 | 本义 | 用法 | 怎么推出来 | 例句 |
| --- | --- | --- | --- | --- |
| **and** | 最早的意思是“接着、然后” | 然后：前一个动作之后接着做 | 本义直接用 | She picked an apple **and** ate it. 她摘了一个苹果，然后吃掉了。 |
| | | 和，并且：把两样东西加在一起 | “说了这个，接着再说那个”，两样东西就被排在一起、加在一起 | I like apples **and** pears. 我喜欢苹果和梨。 |
| | | 用在命令或建议后面，表示结果 | “你先做这件事，接着就会发生那件事”，后一件就是前一件带来的结果 | Eat an apple every day **and** you'll stay healthy. 每天吃一个苹果，你就能保持健康。 |
| | | 口语里用在 go、come、try、stay 这类词后面，代替 to，表示目的 | “去，接着洗”，先去是为了后面那件事，所以后一个动作就是去的目的 | Go **and** wash the apples. 去把苹果洗了。 |
| **but** | 由表示“在旁边”的 by 和 out 合成，本义“在外面” | 除了 | 放“在外面”，就是排除在外，所以是“除了” | Nobody **but** Tom ate an apple. 除了汤姆，谁也没吃苹果。 |
| | | 但是：引出和前面相反或不同的内容 | 前面说的话“之外”还有另一面，引出这另一面，就是“但是” | The apple is small **but** sweet. 这个苹果小，但是很甜。 |
| | | 用在道歉的话后面 | 先表示歉意，再引出和对方期待相反的另一面 | I'm sorry, **but** there are no apples left. 对不起，苹果已经没有了。 |
| **or** | 一个古老的、意思就是“或者”的连词，读音弱化后成了 or。它的意思是“要么、要不然、作为另一个选择”。它和表示“另一个”的 other 不是同一个词 | 或者，还是：引出另一种选择 | 本义直接用：摆出另一种可能 | Do you want an apple **or** a pear? 你要苹果还是梨？ |
| | | 否则：提醒或劝告对方，不这样做就会有坏结果 | or 的意思里本来就有“要不然、否则”：“照我说的做；要不然就是……”，不照做的那种可能，就是坏结果 | Put the apples in the fridge, **or** they'll go bad. 把苹果放进冰箱，不然会坏掉。 |
| | | 用在否定句里，列举两样以上的东西 | or 摆出几个选择，not 把每一个选择都否定掉：哪一个都不 | I don't like apples **or** pears. 我不喜欢苹果，也不喜欢梨。 |
| | | 用在两个数字之间，表示大约 | “六个，或者七个”，把两个数都摆出来，说明说话人拿不准是哪个，就是“大约” | There were six **or** seven apples in the bag. 袋子里有六七个苹果。 |
| **so** | “这样、以这种方式” | 所以：引出结果 | “事情是这样的，于是……”，指着前面已经说过的情况，引出它带来的结果 | The apple was bad, **so** I threw it away. 苹果坏了，所以我把它扔了。 |

**成对的并列连词。** both … and、either … or、neither … nor 前一个词先告诉你“要说两样东西了”，后一个词把第二样接上。前一个词的本义决定了这对词的意思。

| 成对连词 | 前一个词的本义 | 意思怎么来的 | 例句 |
| --- | --- | --- | --- |
| both … and | both 是“两个都、这一个和那一个” | “两个都”，再用 and 把两个加在一起：A 和 B 都 | **Both** Tom **and** I like apples. 汤姆和我都喜欢苹果。 |
| either … or | either 最早是“两个中的每一个”，后来才有“两个中的任意一个” | “两个中任选一个”，再用 or 摆出两个选项：不是 A 就是 B | You can have **either** an apple **or** a pear. 你可以吃一个苹果，或者吃一个梨。 |
| neither … nor | neither 字面是“不”加“两个中的哪一个”，拼写后来向 either 靠拢；nor 是“不”加 or | “两个中哪一个都不”，nor 就是“也不”：A 不，B 也不 | The apple is **neither** big **nor** sweet. 这个苹果既不大，也不甜。 |

三个前一个词的本义里都带着“两个”，所以这三对词都是在两样东西之间说话。

**中考易错点：**

1. 否定句里列举两样东西，用 or 连接：I don't like apples **or** pears（我不喜欢苹果，也不喜欢梨）。原因见上表：or 摆出选项，not 把每个选项都否定掉。
2. so 引出的结果只能放在后面。so 的本义是“这样”，它指着前面已经说出来的情况，所以原因必须先说：The apple was bad, **so** I threw it away（苹果坏了，所以我把它扔了）。不说 So I threw it away, the apple was bad，因为说 so 的时候，前面还没有可以指的情况。

用法依据：[剑桥英汉词典：and](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/and)、[but](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/but)、[or](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/or)、[so](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/so)、[both](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/both)、[either](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/either)、[neither](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD/neither)；[牛津学习词典：and](https://www.oxfordlearnersdictionaries.com/definition/english/and)、[but](https://www.oxfordlearnersdictionaries.com/definition/english/but_1)、[or](https://www.oxfordlearnersdictionaries.com/definition/english/or_1)、[so](https://www.oxfordlearnersdictionaries.com/definition/english/so_3)；[剑桥语法：Conjunctions](https://dictionary.cambridge.org/zhs/%E8%AF%AD%E6%B3%95/%E8%8B%B1%E5%BC%8F%E8%AF%AD%E6%B3%95/conjunctions)、[Conjunctions: contrasting](https://dictionary.cambridge.org/zhs/%E8%AF%AD%E6%B3%95/%E8%8B%B1%E5%BC%8F%E8%AF%AD%E6%B3%95/conjunctions-contrasting)。

### 从属连词：按引导的从句分组

**从属连词放在从句开头，把从句挂到主句上。** 初中要认识两组：引导宾语从句的，和引导状语从句的。这里只讲每个连词的意思从哪里来，从句的分类和详细用法见第四部分“宾语从句：一整句话当宾语”和“状语从句：说明时间、条件、原因等”。

很多从属连词本来就是介词、副词或疑问词，后面改接一整句话，就成了连词。所以它们的意思大多能从原来的词推出来。

| 从句 | 连词和词义 | 本义怎么推出词义 |
| --- | --- | --- |
| 宾语从句 | that 引出一件事，常可省略 | that 本来是指示词“那”。I know that … 就是“我知道那件事：……”，that 指着后面整句话。它只起“指一下”的作用，不添别的意思，所以常可省去 |
| | whether 是否 | whether 本义“两个中的哪一个”。“两种可能中是哪一种”，就是“是否”，所以常和 or not 一起用 |
| | if 是否 | if 的来源不明。if 带的总是一件还没确定的事，英语甚至把“没确定的事”叫作 an if。放在 ask、know 这类词后面，这件没确定的事就是“是不是这样”，所以是“是否” |
| 状语从句：时间 | when 当……时 | when 和 who、what 一样，来自英语里构成疑问词和关系词的那一家。它当连词的用法比当疑问词“什么时候”出现得还早，一开始就是“在……的那个时候” |
| | while 当……时（常指一段持续的时间） | while 本来是名词“一段时间”，今天还说 for a while（一会儿）。当连词就是“在……的那段时间里”，所以从句里常是正在进行、持续一段时间的动作 |
| | before 在……之前 | before 由 by（在旁边）和 fore（前面）合成，本义“在前面”。空间上在前面，时间上就是“在……之前” |
| | after 在……之后 | after 是 off（离开）加上表示“更”的比较级后缀，本义“离得更远”。离得更远就是落在后面，时间上就是“在……之后” |
| | until 直到 | until 的两个部分意思相同，都是“到、一直到”。当连词就是“一直到……那时” |
| | since 自从 | since 本义“在那之后”。当连词就是“从那件事以后（一直到现在）”，所以主句常用现在完成时 |
| | as soon as 一……就 | as 是 all so 磨损后的形式，意思和 so 一样，“这样”。as soon as 就是“和……一样早”：那件事一发生，这件事也跟着发生 |
| 状语从句：条件 | if 如果 | 同上，if 带的是一件还没确定的事。把它当条件：这件事成立了，主句那件事才会发生 |
| | unless 除非，如果不 | unless 来自一个表示“不在比这更弱的条件下”的说法，前半个音节本来是 on，因为整个词带否定意味、又不重读，变成了 un-。意思相当于 except if：“除了……这种情况”，也就是“如果不” |
| 状语从句：原因 | because 因为 | because 就是 by cause，“由于这个原因”，字面就是“因为这个缘故” |
| | since 因为 | 同上，since 本义“在那之后”。“在那件事之后”很容易理解成“由于那件事”，所以又有了“因为”的意思 |
| 状语从句：结果 | so … that 如此……以至于 | so 是“这样”，that 指着后面那件事：“这样……，到了那件事发生的程度” |
| 状语从句：目的 | so that 为了 | “这样做，好让那件事发生”，那件事还没发生，是想要的结果，也就是目的 |
| 状语从句：让步 | although、though 虽然 | though 本义“尽管承认……”：先承认一件事，再说出和它对着干的主句。although 是 all 加 though，all 起强调作用，后来这层强调消失了，两个词意思一样，though 更口语 |
| 状语从句：比较 | than 比 | than 和 then（然后）本来是同一个词，到大约 1700 年拼写才分开。A is bigger than B 最初的意思可能是“A 更大，然后才是 B” |
| | as … as 和……一样 | as 意思同 so，“这样”。as big as B 就是“这样大，就像 B 那样大” |

例句：

- Mom says **(that)** the apples are fresh. 妈妈说这些苹果很新鲜。that 指着后面这件事，引导宾语从句，可以省略。
- **When** I got home, Mom was washing apples. 我到家的时候，妈妈正在洗苹果。when 引导时间状语从句。
- I've eaten three apples **since** I got home. 我到家以后已经吃了三个苹果。since 是“从那以后”，主句用现在完成时。
- Tom is taller **than** me, so he picks the apples on the high branches. 汤姆比我高，所以高处树枝上的苹果由他来摘。

宾语从句还可以用 what、where、who 这类疑问词引导，见第四部分“宾语从句”。

**中考易错点：** while 是连词，后面接句子；during 是介词，后面接名词。这两个词的来历正好说明了区别：while 本来就是“一段时间”，当连词后面接“谁在做什么”；during 本来是一个表示“持续”的动词加 -ing，during the day 的原意是“在这一天持续着的时候”，后面接的是那段时间本身。所以说 I listened to music **while** I was picking apples（我一边摘苹果一边听音乐），或者说 I listened to music **during** lunch（午饭时我一直在听音乐），不说 during I was picking apples。

### 容易混的地方

**1．although 不和 but 连用，because 不和 so 连用。** 除了 both … and 这类成对的连词，连接两部分只用一个连词。典型的错误说法是 Because my alarm didn't go off, so I was late for work。

为什么只能用一个，从两类连词各自的工作就能看出来：

- although 和 because 是从属连词，它们把自己那半句变成从句。从句单独站不住，要挂在一个主句上。
- but 和 so 是并列连词，它们连接两个地位相同、各自站得住的句子。
- 写成 Although A, but B：A 被 although 变成了从句，在等一个主句；B 前面又有 but，被说成和 A 平级的并列句。整句话里找不到主句，A 没处可挂。
- 意思上也重复了：although 本义“尽管承认……”，已经告诉听的人后面要说反过来的话，再加 but 就把“转折”说了两遍。because 是“由于这个原因”，so 是“就这样（于是）”，两个一起用，就把“因果”说了两遍。

中文说“虽然……但是……”“因为……所以……”，两个词成对出现；英语里二选一，保留哪个都可以。

| 错 | 对：只用从属连词 | 对：只用并列连词 |
| --- | --- | --- |
| Although the apple was small, but it was sweet. | **Although** the apple was small, it was sweet. 虽然这个苹果很小，但很甜。 | The apple was small, **but** it was sweet. 这个苹果很小，但很甜。 |
| Because the apple was bad, so I threw it away. | **Because** the apple was bad, I threw it away. 因为苹果坏了，我把它扔了。 | The apple was bad, **so** I threw it away. 苹果坏了，所以我把它扔了。 |

**2．if 有“是否”和“如果”两个意思，从句的时态也不同。** 两个意思都来自“if 带的是一件还没确定的事”：放在 ask、know 后面，是在问这件事是不是真的，就是“是否”；放在主句前后当条件，就是“如果”。时态上的区别见第四部分“主将从现：从句用现在时说将来”。

- I don't know **if** Tom will pick apples tomorrow. 我不知道汤姆明天会不会去摘苹果。（是否）
- **If** Tom picks apples tomorrow, I'll help him. 如果汤姆明天去摘苹果，我就去帮他。（如果）

**中考易错点：** 看到“虽然”“因为”，先确定这句话里只放一个连词。填空题前半句已经有 although 或 because，后半句的空里就不能再填 but 或 so，因为前半句已经是从句，后半句必须是它要挂的主句。

## 感叹词

**感叹词是“插进话里的一声”。** 它的英文名 interjection 拆开看：inter- 是“在……之间”，ject 是“扔”，-ion 变成名词，合起来是“扔到中间的东西”。说话时突然插进来一声“哇”“哎哟”，正是这个意思。

大多数感叹词只是声音，不是真正的词；常放在一句话的开头或结尾，口语里比书面语多见。既然是声音，它们就没有能拆的部分，意思只能从“这一声是在什么情况下发出来的”去理解。

| 感叹词 | 来历 | 用法 | 例句 |
| --- | --- | --- | --- |
| **oh** | 很多语言里都有的一声，用来表达各种情绪 | 听到新情况时的反应；表示惊讶、害怕、高兴 | "The apples are ripe." "**Oh**, are they?" “苹果熟了。”“哦，是吗？” |
| **wow** | 一声天然的惊叹，最早见于苏格兰 | 非常惊讶或佩服 | **Wow**! What a big apple! 哇！好大的苹果！ |
| **oops** | 一声天然的惊呼，在做了笨拙的事时发出 | 出了个小差错，比如东西掉了、打翻了 | **Oops**! I dropped an apple. 哎呀！我把一个苹果掉地上了。 |
| **ouch** | 借自德语里人疼的时候喊的那一声 | 突然感到疼 | **Ouch**! An apple fell on my head! 哎哟！一个苹果砸到我头上了！ |
| **hey** | 可能也是一声天然的喊叫，早先用来挑衅、责备，后来语气变弱 | 引起别人注意，或表示惊讶、生气；也用来打招呼 | **Hey**, don't eat my apple! 嘿，别吃我的苹果！ |

**中考易错点：** 感叹词只是一声，感叹句是一整句话。上表 wow 那一行里，Wow 是感叹词，What a big apple! 是感叹句。what 和 how 引导的感叹句见第三部分“感叹句：what 和 how”。
