# 系动词

**系动词把主语和表语拴在一起，后面跟形容词或名词，说明主语是什么、怎么样。** 系动词自己说不完一句话：The apple tastes 不完整，要说 The apple tastes **sweet**（这个苹果尝起来很甜）。

系动词分三类：

- **be**：本义是“存在、成为”。英语用它加上一个说明的词，讲主语是什么样子、处在什么状态：The apple is sweet 说的是苹果处在“甜”这个状态。
- **感官类**：这些词本来就有两个方向。smell 从一开始就既是“闻到”，也是“发出气味”；taste 最早是“触摸、试探”，14 世纪末有了“尝”的意思，16 世纪起也用来指东西“有某种味道”；look 本来是“用眼睛看”，约 1400 年起也指“呈现某种样子”。人去感知，是实义动词；东西给人某种感觉，就是系动词。
- **变化类**：become 由 be- 加 come 构成，本义是“来到、发生”，12 世纪起指“从一种状态变成另一种”。get 本义是“得到、到达”，到达一种状态就是“变得”。turn 本义是“转动”，12 世纪起既指“转向另一个方向”，也指“从一种东西变成另一种”，由此有了“性质改变”（如颜色、浓度），所以指颜色、天气这类性质的改变。grow 本义是“生长”，长是一点点长的，所以 grow 指逐渐变得。
- **保持类**：keep 本义是“抓住、守住”，15 世纪起有“保持、停留”的意思。stay 本义是“站住”，站着不动就是“保持原样”。

| 类型 | 系动词 | 本义 → 系动词的意思 | 例句 |
| --- | --- | --- | --- |
| be | am、is、are、was、were | 存在 → 是 | The apple **is** sweet. 这个苹果很甜。 |
| 感官类 | look | 看 → 呈现某种样子，看起来 | The apples **look** fresh. 这些苹果看起来很新鲜。 |
| | taste | 尝 → 有某种味道，尝起来 | The apple **tastes** sweet. 这个苹果尝起来很甜。 |
| | smell | 闻、发出气味 → 闻起来 | The apple pie **smells** good. 苹果派闻起来很香。 |
| | sound | 发出声音、被听见 → 听起来、读起来给人某种印象 | Picking apples on the farm **sounds** great. 去农场摘苹果听起来很棒。 |
| | feel | 触摸、感知 → 摸起来；感到 | This apple **feels** soft. 这个苹果摸起来软软的。<br/>I **feel** full after two apples. 吃了两个苹果，我觉得饱了。 |
| 变化类 | become | 来到、发生 → 变成 | The apple farm **became** famous. 这个苹果园出名了。 |
| | get | 到达 → 变得 | I **got** hungry after picking apples all morning. 摘了一上午苹果，我饿了。 |
| | turn | 转动 → 变（颜色、天气等） | The apples **turned** red. 苹果变红了。 |
| | grow | 生长 → 逐渐变得 | The apple tree **grew** taller every year. 苹果树一年比一年高。 |
| 保持类 | keep | 守住 → 保持 | Put on your coat to **keep** warm. 穿上外套保暖。 |
| | stay | 站住 → 保持，依然 | Eat an apple every day to **stay** healthy. 每天吃一个苹果，保持健康。 |

**说“像某个东西”时加 like。** like 本义是“形状相同的”。说“蛋糕看起来像苹果”，蛋糕并不是苹果，只是形状相同，所以要用 like：This cake **looks like** an apple. 这个蛋糕看起来像个苹果。look 后面也可以直接跟名词，如 That looks an interesting book.（那本书看起来挺有意思。）这时说的是“看起来就是一本有意思的书”，书本来就是书，不需要“像”。

**中考易错点：**
- 系动词后面跟形容词，不跟副词。副词修饰动作，可系动词在这里不表示动作，后面的词说的是主语本身：The apple tastes **sweet**，甜的是苹果，不是“尝”这个动作。见第三部分“五种基本句型”。
- 同一个词可能身兼两类，看方向。I **tasted** the apple（我尝了尝苹果）是人去尝，taste 是实义动词，后面跟宾语。The apple **tastes** sweet（这个苹果尝起来很甜）是苹果给人的味道，taste 是系动词，后面跟形容词。look at the apple（看苹果）里的 look 是实义动词，look fresh（看起来新鲜）里的 look 是系动词。
