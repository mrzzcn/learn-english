# 否定前缀：把意思变成“不”

**这一组前缀加在词前，意思就变成反面或错误。** 词性一般不变：前缀只加在开头，词尾没有动，决定词性的后缀还是原来那个，所以 happy 是形容词，unhappy 还是形容词。

| 前缀 | 本义 | 从本义怎么推出来 | 拆词例子 |
| --- | --- | --- | --- |
| **un-** | 不 | 它本身就是否定词头，加在词前直接表示“不……”。它是英语里用得最多的前缀，早在古英语里就组成了一千多个词 | un + happy = **unhappy** 不开心的<br/>un + eaten = **uneaten** 没被吃掉的：an uneaten apple 一个没吃的苹果 |
| **un-**（另一个） | 反着，对着 | 这是另一个 un-，和表示“不”的 un- 来源不同，本义是“对着、反着”。加在动词前，就是把这个动作反着做一遍 | lock 锁上 → **unlock** 反着做，开锁<br/>pack 打包 → **unpack** 反着做，打开包拿出东西：unpack the apples 把苹果从箱子里拿出来 |
| **in-** | 不 | 和 un- 出自同一个表示“不”的老词根。来自拉丁语的词常用 in-，本土词多用 un-，但不少拉丁来源的词也用 un-（如 unusual、unimportant），拿不准就查词典。happy 是本土词，所以是 unhappy；correct、possible、legal、regular 都来自拉丁语，用的是 in- | in + correct = **incorrect** 不正确的 |
| **im-**，在 b、m、p 前 | 不 | 还是同一个 in-，n 被后面的 p 同化成了 m | im + possible = **impossible** 不可能的<br/>im + polite = **impolite** 不礼貌的：polite 本义是“打磨过的”，impolite 最早是“没打磨过的、粗糙的”，后来专指举止粗鲁、不礼貌 |
| **il-**，在 l 前 | 不 | n 被 l 同化 | il + legal = **illegal** 违法的 |
| **ir-**，在 r 前 | 不 | n 被 r 同化 | ir + regular = **irregular** 不规则的：regular 是“有规则的” |
| **dis-** | 分开，朝不同方向 | 两样东西分开 → 走向相反 → “不”。所以 dis- 有三层意思：分开、相反、不 | dis + like = **dislike** 不喜欢：这个词出现在 16 世纪，取代了更早的 mislike，成了 like 的反义词。I dislike sour apples. 我不喜欢酸苹果。<br/>dis + agree = **disagree** 不同意：agree 本义是“合心意”，意见合得来才是“同意”，反过来就是“意见不合” |
| **mis-** | 偏离，走岔 | 走偏了 → 做错了 → “错、坏” | mis + understand = **misunderstand** 理解偏了，误解 |

**两个 un- 会撞车。** unlocked 可以是 un-（不）+ locked（锁着的），意思是“没锁的”；也可以是 unlock（开锁）的过去分词，意思是“被打开了锁”。

- The apple shed was **unlocked**. 苹果棚没锁。／苹果棚的锁被打开了。

两种理解都说得通，要看上下文。

**为什么 in- 会变成 im-、il-、ir-？** 这叫“同化”：n 被后面的辅音拉过去，变得和它相近，读起来更顺口。试着读 inpossible，嘴唇要从 n 急转到 p；把 n 换成 m，双唇一直闭合，就顺多了。

**中考易错点：** 拼写时 m、l、r 不要漏写。illegal 有两个 l，irregular 有两个 r，因为前缀的 n 变成了和后面一样的字母。
