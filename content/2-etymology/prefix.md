# 方向和程度前缀：往哪儿去、做到什么程度

**这一组前缀说明动作的方向、位置、时间先后或程度。** 它们本来大多就是表示方向的小词，意思很具体，加到动词上，动作就有了方向。en- 是例外，它的本义是“放进去、使成为”，所以常把名词或形容词变成动词。

| 前缀 | 本义 | 从本义怎么推出来 | 拆词例子 |
| --- | --- | --- | --- |
| **re-** | 向后，回到原处 | 回到原处 → 回到原来的状态 → 从头再做一遍 → “再、又” | re + port（搬运）= **report**：把东西带回来 → 把消息带回来 → 报告<br/>re + write = **rewrite**：16 世纪最早是“写回去”，也就是回信；18 世纪起才是“再写一遍”，重写。一个词里就能看到“向后”怎么变成“再”<br/>re + tell = **retell** 再讲一遍，复述 |
| **pre-** | 在前面，时间上或位置上都行 | 时间上在前面 → “预先、事先” | pre + view（看）= **preview** 事先看 → 预览，预告<br/>pre + dict（说）= **predict** 事情发生之前说出来 → 预言，预测 |
| **en-**，在 b、p 前写成 **em-** | 放进去；使成为 | 把东西放进去 → 使它变成某个样子。所以加在形容词、名词前，就变成“使……”的动词 | en + large = **enlarge** 使变大，放大<br/>en + courage = **encourage**：courage 最早指“心”，心里的情绪和胆气 → 把胆气放进去 → 给人打气，鼓励<br/>en + joy = **enjoy**：使快乐 → 最早是“高兴”，后来才是“从……中得到快乐”，享受 |
| **de-** | 向下，从……离开 | 从上往下 | de + pend（挂）= **depend**：从上面挂下来 → 挂着的东西靠上面撑着 → 依靠；也引申为“随……而定”<br/>de + scribe（写）= **describe**：写下来，照着描下来 → 描述 |
| **ex-** | 向外，出 | 从里面到外面 | ex + it（走）= **exit** 走出去 → 出去的门，出口<br/>ex + port（搬运）= **export** 运出去 → 出口货物<br/>ex + press（压）= **express**：压出来、挤出来 → 把心里的想法说出来 → 表达 |
| **inter-** | 在……之间 | 两者或多者中间 | inter + national = **international**：国家和国家之间的 → 国际的。这个词是 1780 年才造出来的 |
| **over-** | 在上面；越过 | 在上面 → 越过正常的高度 → 过度，太多 | over + eat = **overeat** 吃得超过了该吃的量，吃得太多 |
| **under-** | 在下面 | 位置在下面 | under + ground = **underground** 地面以下的<br/>under + line = **underline** 在下面画线 |
| **sub-** | 在下面 | 位置在下面 | sub + way（路）= **subway**：1825 年最早指“地下通道”，1892 年起指城市地下铁路 → 地铁 |
| **tele-** | 远 | 隔着很远的距离 | tele + phone（声音）= **telephone** 把声音传到远处 → 电话<br/>tele + vision（看见）= **television** 看见远处的画面 → 电视 |
| **co-**，也写成 **com-**、**con-** | 一起 | 在元音前缩成 co-，在 c、d、n、s、t 等字母前写成 con-，在 b、p、m 前是 com- | co + operate（工作）= **cooperate** 一起工作 → 合作 |

**表里几个词后面接什么，也能从本义推出来：**

- **depend on：** depend 本义是“从上面挂下来”。挂着的东西靠什么撑着，英语用 on，比如 Hang your coat on that hook. 把外套挂在那个钩子上。所以“靠……”是 depend on，“取决于……”也是 depend on：挂在什么上面，就随什么而动。
  - Whether we pick apples tomorrow **depends on** the weather. 我们明天去不去摘苹果，要看天气。
- **encourage sb to do：** encourage 是“给人打气”，打气是为了让人去做一件事，所以后面接这件要去做的事。
  - Mom **encouraged** me **to** try the green apple. 妈妈鼓励我尝尝那个青苹果。
- **enjoy yourself：** enjoy 本义是“使快乐”。“使自己快乐”就是 enjoy yourself，玩得开心。
  - We **enjoyed ourselves** on the apple farm. 我们在苹果园玩得很开心。

例句：

- Don't **overeat**, even if the apples are sweet. 就算苹果很甜，也别吃太多。
- Our town **exports** apples to other countries. 我们镇把苹果出口到别的国家。
- Can you **retell** the story about the apple tree? 你能复述一下那个苹果树的故事吗？

**中考易错点：** 看起来像同一个前缀，意思不一定一样。understand 里的 under 很可能不是“在下面”，而是“在……之间”；enjoy 倒是可以拆成 en- + joy。拿不准的词见本部分最后一节“词源法的局限”。
