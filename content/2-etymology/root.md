# 词根：单词的核心意思

**词根是一个单词的核心意思，前缀和后缀都围着它加。** 很多词根本身不能单独成词，但只要认出它的本义，再配上前缀的方向、后缀的词性，一串单词的意思都能推出来。下表只收初中例词较多的词根。

| 词根 | 本义 | 初中例词：从本义怎么推出来 |
| --- | --- | --- |
| **act** | 推动，驱赶 → 做 | act 做，行动；action 做这件事，行动；active 爱做事的，积极的；actor 做事的人 → 演员；activity 活跃的状态 → 活动 |
| **port** | 搬运 | export 运出去，出口；report 带回来 → 报告；transport 运过去（trans- 是“越过”）→ 运输；important 带进来 → 有分量，重要的（见最后一节） |
| **spect** | 看 | respect 回头看 → 特别留意地看 → 看重，尊重；expect 一直看着等 → 期待 |
| **vis**、**vid** | 看见 | visit 去看 → 拜访；visitor 来看的人；television 看见远处 → 电视；video 本来就是“我看见” → 视频 |
| **dict** | 说 | dictionary 说出来的话 → 词语的书 → 词典；predict 事前说 → 预言 |
| **scrib**、**script** | 写 | describe 写下来 → 描述；description 描述 |
| **form** | 形状 | form 形状，形式；inform 给……一个形状 → 塑造、教导 → 告诉消息，通知；information 信息；uniform 只有一种形状的 → 统一的衣服，制服、校服 |
| **press** | 压 | press 按，压；express 压出来 → 表达 |
| **tract** | 拉 | attract 拉到自己这边 → 吸引；attractive 有吸引力的 |
| **duc**、**duct** | 引导，带领 | introduce 领进来 → 把一个人领到别人面前让大家认识 → 介绍；produce 带出来 → 生产；product 生产出来的东西，产品 |
| **ven**、**vent** | 来 | invent 来到跟前碰上（in- 是“在……上”）→ 找到 → 发明；prevent 抢在前面来 → 挡住，阻止；event 出来的事 → 发生的事，事件 |
| **mov**、**mot** | 移动 | move 移动；movement 运动；motion 运动 |
| **graph** | 写，画 | photograph 用光写出来的 → 照片；geography 对大地的描写 → 地理；paragraph 写在旁边的记号 → 这个记号标出的那一段 → 段落 |
| **phon** | 声音 | telephone 远处的声音 → 电话；phone 是 telephone 的缩短 |
| **cycl** | 圆，轮子 | bicycle 两个轮子 → 自行车；recycle 回到循环里 → 回收再用 |
| **memor**、**mem** | 记得，放在心上 | memory 记忆；remember 再放到心上 → 记起，记得 |
| **nat** | 出生 | nation 生出来的一群人 → 同一祖先、说同一种语言的人 → 民族，国家；national 国家的；international 国际的；nature 出生时的样子 → 本性 → 自然；natural 自然的 |
| **cept** | 拿 | accept 拿到自己这边 → 接受；except 拿出去 → 除了……之外 |
| **fin** | 边界，尽头 | finish 给……划上边界 → 使到尽头 → 完成；final 最后的 |
| **sign** | 记号 | sign 标志；signal 当记号用的 → 信号；design 把记号标出来 → 设计 |

**两个从本义推出来的用法：**

- **prevent sb from doing：** prevent 本义是“抢在前面来”，挡在别人前面，别人就过不去。from 是“离开”，挡住某人，让他离开要做的那件事。
  - The fence **prevents** the deer **from** eating our apples. 篱笆挡住了鹿，不让它们吃我们的苹果。
- **be different from：** different 本义是“各自搬开”，搬开了就是和原来的位置分开了，所以用表示“离开”的 from。different from 英美都用；英式英语也常说 different to，北美英语也常说 different than。
  - Green apples are **different from** red ones. 青苹果和红苹果不一样。

例句：

- The red apples **attract** many **visitors** to the farm. 红苹果吸引了很多游客来农场。
- Can you **describe** the taste of this apple? 你能描述一下这个苹果的味道吗？
- Farmers **produce** a lot of apples here every year. 这里的农民每年产很多苹果。

**中考易错点：** 同一个词根，前缀不同，意思就不同。accept 是“拿到自己这边”，所以是“接受”；except 是“拿出去”，所以是“除了”。只差一个前缀，拼写和读音都接近，想一想“拿进来还是拿出去”就不会写混。
