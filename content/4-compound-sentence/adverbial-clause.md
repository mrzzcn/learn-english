# 状语从句：说明时间、条件、原因等

**状语从句在整句里当状语，说明主句的事在什么时候、什么条件下、为什么发生，结果怎样，等等。** 它由从属连词引导，可以放在主句前面，也可以放在后面。从句在前时，从句末尾加逗号，告诉读者主句从这里开始；主句在前时，一般不加。

初中要掌握七类。每个连词引导什么从句、要注意什么，都来自它的本义。

| 类别 | 连词 | 本义 | 从本义怎么推出来 | 例句 |
| --- | --- | --- | --- | --- |
| 时间 | when | “在什么时候” | when 的词根本来就兼有提问和连接两个用途。when 当连接词（“在……的时候”，at the time that）的用法在最早的英语里就有，比它当疑问词问“什么时候”还要早。所以它引导时间从句，说的就是“在……的时候” | **When** the apples turned red, we picked them. 苹果变红了，我们就摘了。 |
| | while | 名词“一段时间” | “在……那段时间里”，说的是一段持续的时间，所以常和进行时一起用，两件事同时在进行 | Mom was cooking **while** I was washing the apples. 我洗苹果的时候，妈妈在做饭。 |
| | before、after | before 是 by（在旁边）+ fore（前面），“在前面”；after 是 off（离开）加比较级后缀，“离得更远” | 空间上“在前面”“在后面”，用到时间上就是“在……之前”“在……之后” | I ate the apple **after** I washed it. 我把苹果洗了以后才吃。 |
| | until | “一直到” | 状态一直持续，到某个时刻为止。前面是否定时，“不做”的状态一直持续到那一刻，所以 not … until 就是“直到……才”（not before a particular time） | We didn't pick the apples **until** they turned red. 我们直到苹果变红了才摘。 |
| | since | “在那之后” | “从那以后一直到现在”，所以后面接过去的一个起点，主句常用现在完成时，见第五部分 | We have picked apples every year **since** we moved here. 自从搬到这里，我们每年都摘苹果。 |
| 条件 | if | 来源不明 | 表示“某件事要在另一件事发生或成立以后才会发生” | **If** the apples are ripe, we can pick them. 如果苹果熟了，我们就可以摘了。 |
| | unless | un- 在这里不是否定前缀，原来是介词 on；less 是“更少”。本义是“在比这更低的条件下都不行”，也就是 if it be not that | 只有满足这个条件才行，也就是“除非”，相当于 if … not（except if） | You can't have an apple **unless** you finish your homework. 除非写完作业，不然你不能吃苹果。 |
| 原因 | because | by（由于）+ cause（原因），“由于这个原因” | 它起初后面常跟 that，意思是“由于那件事的原因”，所以后面接一个完整的句子。后面只接名词时，要像 the cause of 一样加 of，说成 because of | We didn't pick apples **because** it rained. 因为下雨，我们没去摘苹果。<br/>We didn't pick apples **because of** the rain. 因为这场雨，我们没去摘苹果。 |
| | since、as | since 是“在那之后”；as 是 all + so，“完全这样” | 一件事在另一件事之后发生，常被看作由它引起，since 就这样从“从那时起”引申出“由于”。as 也能表示原因，相当于 because | **Since** it was raining, we stayed at home. 因为在下雨，我们待在家里。 |
| 结果 | so … that、such … that | so 本义“这样、如此”；such 是 so 加上“形状、样子”，“这样一种的” | so 说程度，“到这样的程度”，所以后面接形容词或副词；such 说“这样一种东西”，所以后面接名词短语。that 指着后面那个结果 | The apple was **so** sour **that** nobody ate it. 这个苹果酸到谁都没吃。<br/>It was **such** a big apple **that** we shared it. 这个苹果太大了，我们分着吃了。 |
| 目的 | so that | so 本义“这样” | “这样做，好让那件事发生”，所以是目的“以便”（in order that）。说的是希望发生、还没发生的事，所以从句里常用 can、could、will、would | Mom put the apples in the fridge **so that** they would stay fresh. 妈妈把苹果放进冰箱，好让它们保持新鲜。 |
| 让步 | although、though | though 本义就是“尽管、即使”；although 是 all + though，all 用来加强语气 | all 起加强作用，合起来是“即使……也”，承认前面的事实，后面的事照样发生，由此表示让步 | **Though** it was raining, we went on picking apples. 虽然在下雨，我们还是接着摘苹果。 |
| 比较 | than、as … as | than 由 then（然后）分化而来；as 是 all + so，“完全这样” | bigger than B 最初很可能是“更大，然后才是 B”，所以 than 跟在比较级后面。as … as 是“同样这样……，就像……那样”，所以中间用原级；否定说 not as … as，“没到那样的程度” | I picked **as many** apples **as** I could. 我尽量多摘苹果。<br/>The apples were **not as** expensive **as** I thought. 这些苹果没有我想的那么贵。 |

**中考易错点：**

1. so that 和 so … that 只差一个位置。so 和 that 被形容词或副词隔开时，so 说的是这个形容词的程度，“到这样的程度，以致于”，表示结果；so that 连在一起时，so 说的是整件事“这样做”，“好让……”，表示目的。
2. although、though 不和 but 连在一起用。一个句子里有两个分句，只需要一个连接词把它们连起来；although 已经把“尽管”的关系连好了，再加 but 就连了两遍。另外，although 或 though 分句放在主句后面时，意思本身就接近 but。
3. 时间和条件状语从句说将来的事，用一般现在时，见下一节“主将从现”。
