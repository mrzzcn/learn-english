# 现在完成时 ★

**现在完成时说过去发生的事和现在有联系：到现在为止的经历，刚刚完成的事，结果留到现在的事，从过去一直持续到现在的状态。**

```
过去 ──●═══════════════════【现在】──────→ 将来
```

事情在过去发生或开始，说的重点是它和现在的关系，不说具体哪一天。

**构成：** have 或 has + 过去分词。否定在 have 后面加 not（haven't、hasn't）；疑问把 have 或 has 提到主语前面。

**为什么说的是“到现在为止”：从“手里拥有一个做完的结果”推出来。**

1. **have 的本义是“拥有、持有”。** 它还有一个意思：“使某人或某物处于某种状态”，例句是 I want to have everything ready in good time.（我想及早把一切准备好。）现在也能说 I have the apples ready.（我把苹果准备好了。）结构是：have + 东西 + 这个东西现在的状态。
2. **过去分词说的是“做完了的状态”。** a washed apple 就是一个洗好了的苹果，洗这个动作已经做完。
3. **两者放在一起，就是“拥有一个做完的结果”。** 完成时就是从这种说法来的：have 表示拥有，过去分词像形容词一样说宾语的状态，好比 I have the work done（我手里有一份做完的工作）。再比如 I have the apples washed.（我把苹果洗好了。）这句话同时说了两件事：我已经做成了一件事，这个结果现在还保持着。
4. **后来说话人把这个结构重新理解了。** 宾语挪到了过去分词后面，have 不再是“拥有”，而是把“做完”和“现在”连起来：I have washed the apples.（我已经把苹果洗好了。）
5. **所以现在完成时一半说过去，一半说现在。** 过去分词说动作已经做完，have、has 是现在时，说这个结果现在还“在手里”。这就是它总和“到现在为止”连在一起的原因。现在完成时说的正是 time up to now，也就是“到现在为止”的时间。

| 用法 | 常配的词 | 从本义怎么推出来 | 例句 |
| --- | --- | --- | --- |
| 到现在为止的经历 | ever、never、before | ever 本义“在任何时候”，never 是 not + ever，“在任何时候都没有”。问的是“到现在为止的任何时候”，所以配现在完成时 | **Have** you ever **picked** apples? 你摘过苹果吗？<br/>I **have never picked** apples before. 我以前从没摘过苹果。 |
| 刚刚完成 | just | just 很早就有“恰好、精确”的意思，时间上“只差一点”，引申为“就在刚才”。刚做完的事，结果还在眼前 | Mom **has just washed** the apples. 妈妈刚把苹果洗好。 |
| 已经完成或还没完成 | already、yet | already 是 all + ready，本义“完全准备好了”，所以是“已经”；yet 指“从过去开始一直到现在”的时间，主要用在否定句和疑问句里 | I **have** already **eaten** two apples today. 今天我已经吃了两个苹果。<br/>Tom **hasn't washed** the apples yet. 汤姆还没洗苹果。 |
| 从过去持续到现在 | for、since、How long …? | 见下面“现在完成时的 for 与 since” | We **have had** this apple tree **for** ten years. 这棵苹果树我们家已经有十年了。 |

**标志词：** already、yet、just、ever、never、before、so far、recently、for + 一段时间、since + 过去的时间点。它们都在说“到现在为止”。

**中考易错点：**

1. **have been to 和 have gone to。** be 的本义是“存在、处于”，has been to 是“曾经在那儿待过”，表示一次已经完成的来回，人已经回来了。go 的本义是“走、离开”，has gone to 是“走了，走的结果留到现在”，表示这趟行程还没结束，人现在不在这儿。Tom **has been to** the apple farm. 汤姆去过苹果园。Tom **has gone to** the apple farm. 汤姆去苹果园了，现在不在这儿。
2. **already 的位置。** already 一般放在第一个助动词后面、主要动词前面，不放在动词和宾语之间。说 I've **already** eaten the apple，不说 I've eaten already the apple。yet 一般放在句末，主要用于否定句和疑问句。
