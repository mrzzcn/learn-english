# 过去完成时

**过去完成时说在过去某个时间之前已经发生或完成的事，也就是“过去的过去”。**

```
过去 ──●════════▲──────────────【现在】──→ 将来
```

▲ 是过去的参照时间，● 那件事发生在它之前。

按“时间只改第一个词”，把现在完成时的 have 换成 had，站的位置就从“现在”挪到了“过去某一刻”。从本义看：had 是过去时，说的是“在过去那一刻，手里已经有了一个做完的结果”。两者正好对照：现在完成时说“到现在为止”，过去完成时说“到过去那一刻为止”。

| 句式 | 构成 | 例句 |
| --- | --- | --- |
| 肯定 | had + 过去分词 | When Tom got to the farm, we **had** already **picked** all the apples. 汤姆到农场时，我们已经把苹果全摘完了。 |
| 否定 | hadn't + 过去分词 | By last Friday, we **hadn't sold** any apples. 到上周五，我们一个苹果都还没卖出去。 |
| 疑问 | Had + 主语 + 过去分词？ | **Had** the apples **turned** red by the end of September? 到九月底，苹果已经变红了吗？ |

过去完成时也常出现在主句是过去时的宾语从句里：Tom said he **had eaten** the apple. 汤姆说他已经把苹果吃了。这是宾语从句“往过去退一步”的结果，见第四部分“宾语从句”。

两件事紧挨着发生，都用一般过去时就行：Everyone clapped when Tom picked the first apple. 汤姆摘下第一个苹果时，大家都鼓起掌来。要强调一件事在另一件事之前已经完成，才用过去完成时。

**标志词：** by + 过去的时间（by last Friday、by the end of last year）、by the time + 一般过去时的从句、when 或 before + 一般过去时的从句、already。by 本义是“在旁边、靠近”，它也表示“不晚于、在……或之前”：by last Friday 就是“不晚于上周五”，到那一刻为止，所以配“到过去那一刻为止”的过去完成时。

**中考易错点：** 两件过去的事，要强调先发生的那件在另一件之前已经完成，先发生的那件用过去完成时。说 The apple festival was cancelled, but we **had** already **bought** the tickets（苹果节取消了，可我们早就买好了票），不宜说 we already bought the tickets。口语里（尤其是美国英语）也有人这样说，中考按过去完成时。
