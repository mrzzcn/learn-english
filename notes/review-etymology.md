# 审查报告：按"从本义推导"的标准检查各模块

审查日期：2026-09-24。标准来自会话 f05c983d 对 important 的解析。本义均查自 etymonline，链接格式 `https://www.etymonline.com/word/<词>`。

## 一、标准：important 的解析是怎么写的

| 步骤 | important 的写法 |
| --- | --- |
| 1. 拆词 | im-（进入）+ port（搬运）+ -ant（形容词后缀） |
| 2. 本义 | 拉丁语 importare："带进来" |
| 3. 推导 | 带进来的东西会带来后果，所以引申为"有分量的、重要的" |
| 4. 辨析 | 拉丁语有两个 in-：一个是"进入"，和介词 in 同源；一个是"不"，和 un- 同源。两个在 p、b、m 前都变成 im-，所以只看拼写分不出 |
| 5. 判断方法 | 去掉前缀，看剩下的是不是现成形容词的反义 |

关键在于：**每个结论前面都有一条从本义出发的推导链，读者能自己推出结论，而不是背下结论。**

## 二、总体结论

**全部模块都是"先给规则，再举例子"的写法，没有一个模块做到了"从本义推导"。** 问题不在个别小节，而是写法本身。需要按新结构整体改写，局部修补解决不了。

造成这个问题的原因在写作规范本身，责任在我：

- **规范第 5 条**写了"不加编者想象的解释"，写作者就把一切推导都当成想象删掉了。
- **规范第 7 条**写了"不写演变过程"，我在修正时还删掉了"improve 里的 im- 来自 en-"这类推导。

这两条都把"不堆砌历史形式"错当成了"不写推导"。规范需要改成：**推导必须写，推导的每一步都要有 etymonline 或词典义项作依据；历史形式只写推导需要的那一个。**

## 三、事实错误：第二部分"词源法的局限"一表

这张表本来要讲"不能拆"，但有两个词恰恰能拆，另外三个只给了结论。

| 单词 | 表里现在的说法 | etymonline 的本义 | 应该怎么写 |
| --- | --- | --- | --- |
| **enjoy** | 不能这样拆 | en-（使）+ joy（快乐），本义"使快乐、感到快乐" | **表里写错了。** 这个词能拆，应该移到正面例子里 |
| **understand** | 不能这样拆，不是"站在下面" | 很可能是"站在中间"。这里的 under 不是"下面"，而是另一个意思"在……之间" | 拆法对，但 under 的意思变了。应该写出推导："站在事情中间"，所以"弄明白" |
| **important** | im- 不是否定前缀 | in-（进入）+ portare（搬运），"带进来" | 按会话 f05c983d 的五步写 |
| **improve** | im- 不是否定前缀 | en-（使）+ prou（利益），本义"使有利" | 写出推导："使有利"，所以"改进"。这里的 im- 其实来自 en- |
| **invite** | in- 不是否定前缀 | 拉丁语 invitare，来源不明 | 这是真正推不出来的词。要写明"来源不明"，这才是"局限"该放的例子 |

## 四、各模块的问题和应有的推导

下表每行列一个典型问题。每个模块里同类问题还有很多，改写时要逐条处理。

### 第一部分：十大词性

| 模块 | 现在只给了结论 | 本义 | 应有的推导 |
| --- | --- | --- | --- |
| 冠词 | "a 用在辅音音素前，an 用在元音音素前" | an 来自古英语 ān，本义"一"。a 是 an 在辅音前脱掉 n 的形式 | an 本来就是"一"。在辅音前 n 脱落成了 a，所以判断标准是读音，不是字母 |
| 冠词 | "a 还能表示'每'"（five yuan a kilo） | 同上，本义"一" | "一公斤五元"，也就是"每公斤五元" |
| 冠词 | "the 表示就是那一个" | 来自古英语的指示词 se，本义"这、那" | the 本来就是"那"，所以用在说话双方都知道的东西前面 |
| 代词 | any 的用法 | 本义"一个的"，和 one 同源 | any apple 就是"随便哪一个苹果"。所以它常用在疑问句和否定句里 |
| 代词 | each 与 every | each 是"永远一样"；every 是 ever + each，"每一个，一个不落" | every 是在 each 前面加了 ever 来强调，所以 every 更强调"全部" |
| 代词 | either 与 neither | either 是"两个中的每一个"；neither 是"两个中的哪个都不" | 本义里就带着"两个"，所以只能用于两者 |
| 代词 | other 与 another | other 是"第二个"；another 是 an + other | another 就是"再一个"，所以后面接单数 |
| 代词 | it 的用法 | 来自指示词，本义"这" | 先指代前面提到的东西，再发展出形式主语的用法 |
| 形容词 | 比较级和最高级 | more 是"更大的"，most 是"最大的"，都来自"大"这个词 | more 就是"更"，所以长词前面加 more |
| 副词 | -ly 构词 | 来自 -lic，本义"形状、身体"，和 like 同源 | friendly 是"有朋友的样子"，quickly 是"以快的样子"。所以名词加 -ly 是形容词，形容词加 -ly 是副词 |
| 副词 | already、yet、still、ago | already = all ready，"完全准备好"；still 本义"不动"；ago = gone，"过去了" | already 是"已经全准备好"，still 是"没动，还是原样"，所以才有"已经""仍然""……以前"的意思 |
| 动词 | can、could | 古英语 cunnan，"知道"，也就是知道怎么做 | "知道怎么做"，所以是"会、能"，再引申出"可以" |
| 动词 | may、might | "有能力、有力量" | 有能力做，引申为"允许"，再引申为"有可能" |
| 动词 | must | 古英语 motan（"不得不"）的过去式 | "不得不"，所以是"必须"。"必然如此"，所以推测时是"一定是" |
| 动词 | should、shall | shall 本义"我欠、他欠"，should 是它的过去式，保留了"义务"的意思 | "欠着"，所以是"应该做"，再引申为建议 |
| 动词 | will、would | "想要、希望" | 想要做，所以"打算做"，再引申为"将要"。would 是 will 的过去式，所以过去将来时用 would |
| 动词 | have 作助动词 | "拥有、持有" | 见第五部分时态一行 |
| 动词 | to do 与 doing | to 的本义是"朝向" | 已经从本义推导了，是全文唯一做到的一节。但 suggest doing 这类例外只写了"要记"，应该说明为什么推不出来 |
| 介词 | of | 本义"离开、从……出来"，和 off 同源 | a piece of apple 是"从苹果上取下的一块"；be made of 是"由……构成"。所有格"的"也要从这里推 |
| 介词 | for | 本义"在……前面" | "在前面"，引申为"为了"，再引申为"代替、交换" |
| 介词 | with | 本义"对着、反对"，后来才变成"和……一起" | fight with 为什么是"和……打"：本义就是"对着" |
| 介词 | about | 本义"在外面一圈、周围" | "周围"，所以是"大约"，再引申为"围绕某个话题"，也就是"关于" |
| 介词 | after | off 加比较级后缀，"更远离" | "离得更远"，所以是"在后面"，再引申为"在……之后" |
| 介词 | before | by + fore，"在前面" | 空间上"在前面"，所以时间上"在之前" |
| 介词 | between、among | between 是"两个"；among 是"在人群中"，和 mingle（混合）同源 | 本义就说明了为什么 between 用于两者，among 用于一群 |
| 介词 | during | 本义"持续"，来自拉丁语"变硬" | "在……持续的整个过程中" |

## 五、需要你决定的问题

1. **没有词源可推的句法规则怎么写。** 比如五种句型、反意疑问句、主谓一致。我的建议是从"它在句子里干什么"推，比如反意疑问句为什么重复助动词：因为英语疑问句本来就是把助动词提前。这一步标成"逻辑推导"，和"词源推导"分开。
2. **推不出来的词怎么写。** 比如 if、invite、suggest doing。我的建议是明写"来源不明"或"本义推不出现在的用法"，并说明原因，不硬编一条推导。
3. **历史形式写到什么程度。** important 的例子写了拉丁语 importare。我的建议是每条推导最多写一个历史形式（一个拉丁词或一个古英语词），不写原始印欧语和中间形式。
4. **改写方式。** 这次是整体改写，工作量和上次写作相当。我建议沿用上次的方式：每个模块一个写作单元并行改写，再加一轮审校，专查每条推导是否有 etymonline 依据。

## 六、规范要改的地方

- 写作规范第 5 条改为：用法只取词典义项；**每个用法都要写出从本义到用法的推导链，推导的每一步要有 etymonline 或词典依据**；没有依据的推导不写，推不出来的要明说。
- 写作规范第 7 条改为：**推导必须写**；历史形式只写推导需要的那一个，不堆演变链。
- 新增一条：用法、搭配、规律一律不能只给结论，也不能按"固定搭配"直接列出。
